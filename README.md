# Homebrew Tap for Cubrim

[Cubrim](https://cubrim.com) — N-dimensional-cube lossless compressor and `.cbr` archiver.

## Install

```sh
brew install arcanada-one/cubrim/cubrim
```

or:

```sh
brew tap arcanada-one/cubrim
brew install cubrim
```

## Usage

```sh
cubrim --version
cubrim --help
cubrim a archive.cbr file-or-dir
cubrim x archive.cbr -o restored
```
